# Ателье кожаных изделий

**Параметрический конфигуратор изделий из кожи: чехлы и картхолдеры.**
Один HTML-файл, который превращает размер устройства или стек карт в готовый производственный пакет: 3D-превью, точную выкройку в миллиметрах, PDF-листы A4 для печати 1:1, расчёт расхода кожи, пошаговую 3D-сборку узлов и техкарту изготовления.

> Проект не требует сборки, бэкенда, npm и базы данных. Открывается в браузере, работает локально, состояние хранится в `localStorage`.

## Назначение и философия

Кожевенное дело начинается не с ножа, а с_correctной выкройки_. Большинство ошибок новичков и даже опытных мастеров — это неверный припуск, забытая прибавка на обхват торца, лишняя боковина на тонком корпусе или фурнитура, установленная после сшивания.

Проект решает это одним связанным контуром:

```
Размер изделия → Тип кроя → Геометрия деталей → 3D → Выкройка → PDF → Расход кожи → Сборка → Техкарта
```

Все звенья питаются **из одного источника размеров**. Изменение толщины кожи на 0,2 мм одновременно пересчитывает внешний габарит, длину полосы дна, положение сгибов, площадь раскладки, количество стежков, вес изделия и состав операций в техкарте.

Два принципиальных решения:

- **Адаптивная кромка.** Боковина (ластовица) добавляется только когда она действительно нужна. Тонкий MacBook, iPad, Kindle или стек из 3 карт шьются плоским кроем из двух панелей — как это делают в реальных ателье.
- **Гейтинг результата.** 3D-превью, выкройка и все кнопки скачивания заблокированы, пока не выбраны модель/формат и конструкция. Нельзя случайно скачать раскрой «по умолчанию» и испортить кожу.

## Возможности

### Конфигурирование
- Две продуктовые линии: **чехлы** (11 конструкций) и **картхолдеры/кошельки** (11 конструкций).
- Каталог из **~250 устройств**: ноутбуки, планшеты, электронные книги — включая снятые с производства модели (MacBook 2008, iPad 1, Kindle DX, Sony PRS, Nook Classic).
- Поиск по названию, фильтр по бренду, группировка `optgroup`, пометка `▸ кромка` прямо в списке моделей.
- Ручной ввод габаритов A/B/C с шаговыми кнопками — для нестандартных устройств, болванок, чехлов «на вырост».
- Для картхолдеров: 6 форматов карт, счётчик вместимости 1–14, ориентация (горизонтальная/вертикальная), автоматический расчёт толщины стека.

### Материалы
- 8 предустановленных оттенков кожи + произвольный цвет через `input[type=color]`.
- 3 отделки: Crazy Horse (пуллап), гладкая, сафьян — **влияют на предел гибкости** и, следовательно, на тип кроя.
- Толщина кожи **0,6–4,0 мм** с шагом 0,1 — участвует во всех расчётах.
- Слайдер патины/износа 0–100 % — управляет плотностью царапин в процедурной текстуре.
- 4 варианта нити (кремовая, в тон, чёрная, красная) — цвет нити виден в 3D и на стежках.
- 3 варианта подкладки (замша 0,7 / кожа 0,8 / без подкладки) — влияет на гибкость и расход.

### 3D
- Фотореалистичное PBR-превью на Three.js: процедурные albedo/normal/roughness карты кожи, замша с sheen, латунь, алюминий, деревянный стол.
- ACES Filmic tone mapping, PMREM-окружение, мягкие статические тени, пылинки в луче света, туман.
- OrbitControls с демпфированием, автовращение с паузой при взаимодействии и возвратом через 5 с.
- Три уровня качества (DPR ×1 / ×1,5 / ×2 и разрешение теней 1024/2048).
- Регулировка силы и угла света, угол раскрытия клапана/книжки/веера, показ наполнения.
- **Graceful degradation:** при недоступности WebGL или CDN автоматически включается 2D-эскиз, а раскрой, PDF, расчёт кожи и техкарта продолжают работать полностью.

### Раскрой и печать
- SVG-выкройка **в физических миллиметрах**: контур реза, линия шва, сгибы, отверстия, метки, линии обхвата, долевая.
- Экранная линейка с калибровкой 100 мм под реальную линейку.
- **PDF A4 210×297 мм** через jsPDF: калибровочный лист + все детали.
- Каждая помещающаяся деталь — **отдельный лист**. Крупные автоматически режутся на листы с перекрытием 8 мм, крестами и **точками склейки V/H**.
- Выбор DPI: 200 / 300 / 400.
- Системная печать как fallback, если CDN jsPDF недоступен.

### Расход кожи
- Чистая площадь, площадь с запасом 5–40 %, фут², объём в см³, вес в граммах.
- Таблица 13 форматов: A5, A4, A3, A2, Letter, Legal, обрезок 20×20, крафт 30×30/30×40/50×50, 1 фут², 1 м², чепрак 140×100.

- **Сравнение кроя**: таблица «без кромки / с кромкой» с площадью, длиной шва, числом листов и рекомендацией.

### Сборка и документация

## Ключевая логика: адаптивная кромка

### Что такое кромка

**Кромка (боковина, ластовица)** — отдельная полоса кожи по периметру, задающая глубину изделия. Она нужна не всегда.

- **Плоский крой (без кромки).** Две панели, шов по трём сторонам. В разрезе изделие — «линза»: кожа сама обхватывает торец. Так шьют чехлы для MacBook Air, iPad, Kindle и минималистичные картхолдеры.
- **Крой с кромкой.** Панели по размеру изделия + полоса, задающая глубину. Нужна для толстых корпусов и больших стеков карт.

### Предел плоского кроя

```
предел = (base + k₁ × t) × flex

где:
  base = 10   для чехлов
         5    для картхолдеров
  k₁   = 3    для чехлов
         3,4  для картхолдеров
  t    = толщина кожи, мм
  flex = flex(отделка) × flex(подкладка)
```

| Отделка | flex |
|---|---|
| Crazy Horse | 1,00 |
| Гладкая | 0,92 |
| Сафьян | 0,82 |

| Подкладка | flex |
|---|---|
| Без подкладки | 1,00 |
| Замша 0,7 мм | 0,95 |
| Кожа 0,8 мм | 0,90 |

**Пример.** Кожа 2,2 мм, Crazy Horse, замша:
`предел = (10 + 3 × 2,2) × 1,00 × 0,95 = 15,8 мм`

- MacBook Air 13 (11,3 мм) → **без кромки**
- MacBook Pro 14 (15,5 мм) → **без кромки**
- MacBook Pro 16 (16,8 мм) → **с кромкой**
- Игровой ноутбук (25 мм) → **с кромкой**

Тот же расчёт для картхолдера: `(5 + 3,4 × 1,4) × 1,00 × 1,00 = 9,8 мм` → 6 карт (4,8 мм) плоский крой, 12 карт (9,6 мм) ещё плоский, 14 карт (11,2 мм) уже боковина.

### Прибавка на обхват

Для плоского кроя панели расширяются, чтобы кожа покрыла торец:

```
обхват = π/2 × (C + t) − C
```

Это разность полуобхвата «стадиона» (прямоугольник со полностью скруглёнными торцами) и плоской ширины. Прибавка идёт **в ширину** панелей целиком и **в половину размера — в высоту** (низ зашивается, верх открыт).

**Пример.** MacBook Air: C = 11,3; t = 2,2 →
`обхват = 1,5708 × 13,5 − 11,3 = 9,9 мм`

### Режимы

| Режим | Поведение |
|---|---|
| **Авто** | Кромка включается, если `C > предел` |
| **Без кромки** | Принудительно плоский крой. Если C выше предела — предупреждение о тугой посадке |
| **С кромкой** | Принудительная боковина. Если C ниже предела — предупреждение о перерасходе |

**Исключения.** Конструкции `ch_zip` (замкнутый контур молнии) и `ch_acc` (гофре) требуют боковины **по замыслу** — режим игнорируется, кромка всегда включена, в панели контроля это явно указано.

## Расчётные формулы

Все величины в миллиметрах, если не указано иное.

### Габариты

```
Wi = A + посадка                     внутренний размер по ширине
Hi = B + посадка                     внутренний размер по высоте
Ci = C + 4      (чехлы)              внутренний зазор по толщине
Ci = C + 2      (картхолдеры)

depth = Ci, если кромка; иначе C     рабочая глубина

finW = Wi + обхват, если плоский; иначе Wi
finH = Hi + обхват/2 (чехлы, плоский)
finH = Hi (остальные случаи)

крой:  W = finW + 2 × припуск
       H = finH + 2 × припуск

снаружи: finW + 2t × finH + 2t × depth + 2t
```

### Радиусы

```
r  = min(12, Wi/4, Hi/4)             чехлы
r  = min(6, finW/5, finH/5)          картхолдеры
rc = r + припуск                     радиус по контуру реза
```

### Полоса дна (чехлы, с кромкой)

```
L = 2 × (Hi − 2r) + (Wi − 2r) + 2π × (r + t/2)
ширина полосы = Ci + 2t + 2 × припуск
```

Длина считается по **нейтральной линии** кожи (радиус `r + t/2`) — иначе на углах полоса окажется короткой.

### Боковина картхолдера на молнии

```
L = 2 × (finW − 2r) + 2 × (finH − 2r) + 2π × (r + t/2)
```

Замкнутый контур: молния идёт по трём сторонам, четвёртая замыкается швом.

### Сгиб клапана через торец

```
сгиб = π × (depth/2 + t) + 2
```

### Шов, нить, стежки

```
длина шва = Σ периметр(линия шва) × количество
шаг       = 3,0 мм                     картхолдеры
          = 3,0 / 3,5 / 4,0 мм         чехлы (t ≤ 2 / 2–3 / ≥ 3)
стежков   = длина шва / шаг
нити      = длина шва / 1000 × 2,5 + 0,3   (м, седельный шов в 2 нити + запас)
```

### Площадь, объём, вес

```
площадь  = Σ (Ш × В) × количество / 10000        дм²
с запасом = площадь × (1 + запас/100)
фут²      = площадь с запасом / 9,2903
объём     = площадь × 100 × (t/10)               см³
вес       = объём × 0,86                         г  (плотность кожи ≈ 0,86 г/см³)
урез      = Σ периметр(контур реза) × количество / 1000   м
```

### Оценка времени

```
база   = 3,0 ч (чехлы) / 1,5 ч (картхолдеры)
       + площадь / 8
       + отверстия × 0,12 (чехлы) / 0,10 (картхолдеры)
       + длина шва/1000 × 1,2
       − 0,8 ч (чехлы) / 0,3 ч (картхолдеры), если плоский крой
```

### Раскладка (shelf packing)

Детали сортируются по убыванию максимального габарита, размещаются полками с зазором 4 мм, поворот на 90° разрешён. Деталь больше листа помечается `⚠` и не учитывается в листax — это сигнал выбрать формат крупнее.

### Тайлинг A4

```
печатная область = 190 × 277 мм (поля 10 мм)
перекрытие       = 8 мм
шаг тайла        = 182 × 269 мм
число тайлов     = ceil((габарит − 8) / шаг)
```

## Подробный порядок работы

Ниже — полный производственный цикл: от запуска приложения до готового изделия.

### Шаг 0. Запуск и знакомство с интерфейсом

1. Откройте приложение. Вы увидите заголовок, две крупные кнопки выбора линии и подсказку «Готовность 0/2».
2. 3D-сцена закрыта замком с чек-листом — это нормально. Так приложение защищает от случайного раскроя.
3. Прокрутите страницу вниз, чтобы увидеть все разделы: правило кромки, скачивание, выкройка, спецификация, расход кожи, референсы, сборка. Пока они пустые — заполнятся после выбора.

### Шаг 1. Выбор продуктовой линии

Нажмите одну из двух карточек:

- **Чехлы** — если делаете чехол для ноутбука, планшета или электронной книги.
- **Картхолдеры** — если делаете картхолдер, кошелёк, зажим для денег.

При переключении приложение:
- подменяет панель параметров (каталог устройств ↔ формат карты и вместимость);
- подменяет сетку конструкций (11 ↔ 11);
- подменяет референсы;
- **запоминает ваши настройки для каждой линии отдельно** (посадка, припуск, толщина, подкладка, запас, формат раскладки) и восстанавливает их при возврате;
- сбрасывает гейтинг — модель и конструкцию нужно выбрать заново.

> Значения по умолчанию: чехлы — посадка 6 мм, припуск 6 мм, кожа 2,2 мм, замша, запас 15 %, раскладка A4. Картхолдеры — посадка 2 мм, припуск 4 мм, кожа 1,4 мм, без подкладки, запас 12 %, раскладка «обрезок 20×20».

### Шаг 2. Задание габаритов

#### Для чехлов

1. Выберите тип: **Ноутбуки / Планшеты / Э-книги**.
2. При необходимости сузьте список фильтром бренда или строкой поиска. Поиск понимает частичные запросы: `air 2015`, `ipad 2`, `kindle`, `prs-t`.
3. Выберите модель из списка. Габариты A/B/C подставятся автоматически, гейтинг по устройству закроется, появится тост с названием и вердиктом по кромке.
4. **Проверьте габариты штангенциркулем.** Особенно толщину: у ноутбуков она часто указана без ножек, у планшетов — без камеры, у э-книг — без чехла-книжки.
5. Если устройства нет в каталоге — выберите «Свой размер (вручную)» и введите A/B/C. Кнопки `−` / `+` меняют значение с шагом 1 мм (A, B) и 0,5 мм (C).

#### Для картхолдеров

1. Выберите формат карты (ID-1, ID-1 с эмбоссированием, визитка, пропуск, права, паспорт).
2. Задайте количество карт слайдером 1–14. Толщина стека C пересчитается автоматически, поле C станет нередактируемым.
3. Выберите ориентацию: горизонтально (карта входит длинной стороной) или вертикально.
4. При необходимости скорректируйте A/B вручную — например, если карты в холдерах или ламинате.

### Шаг 3. Посадка и припуск

| Параметр | Что делает | Рекомендации |
|---|---|---|
| **Посадка** | Прибавка к внутреннему размеру | Чехлы: 4–8 мм. Картхолдеры: 1,5–3 мм. Менее 2 мм (чехлы) / 1 мм (карты) — панель подсветится жёлтым |
| **Припуск** | Расстояние от контура реза до линии шва | Чехлы: 5–8 мм. Картхолдеры: 3–5 мм. Менее 3 мм — риск прорезания по шву |

Оба параметра сразу перерисовывают выкройку, меняют длину шва, число стежков и расход кожи.

### Шаг 4. Проверка решения по кромке

1. Найдите блок **«03 · Кромка · боковина»**. В нём:
   - пилюля `БЕЗ КРОМКИ` (зелёная) или `С КРОМКОЙ` (янтарная);
   - числа `C … / предел … мм`;
   - шкала с красной риской предела;
   - текстовое объяснение решения.
2. Оставьте **Авто**, если доверяете расчёту — это рекомендуемый режим.
3. Переключите **Без кромки**, если хотите плоский крой осознанно (например, кожа мягкая, хромовая, и вы уверены в растяжимости).
4. Переключите **С кромкой**, если нужна структурная жёсткость или планируете подкладку-карман.
5. Прокрутите к разделу **«05 · Правило»** — там формула, живой пересчёт и таблица типичных изделий/стеков с вердиктом при текущей коже. Это лучший способ понять логику.

> Для картхолдера на молнии и аккордеона переключатель не отключит боковину — она нужна по конструкции. Приложение сообщит об этом в подсказке.

### Шаг 5. Выбор конструкции

1. В блоке **«04 · Конструкция»** нажмите карточку. Активная подсвечивается латунной рамкой.
2. Гейтинг закрывается полностью — замок с 3D исчезает, инициализируется сцена, заполняются все разделы ниже.
3. Появится тост с названием конструкции и типом кроя.

**Как выбирать:**

- Тонкое устройство, минимум操作的 → `slip` (чехол) или `ch_slip` (карты).
- Нужен быстрый доступ к картам → `ch_slots`, `ch_pull`, `ch_fan`.
- Нужны купюры → `ch_bifold`, `ch_long`, `ch_clip`.
- Карты не должны выпадать → `ch_snap`, `ch_mag`, `ch_zip`.
- Много карт → `ch_acc`.
- Чехол с фиксацией → `stud`, `lock`, `strap`, `handle`.
- Чехол-трансформер → `folio`, `roll`.

### Шаг 6. Настройка материала

1. **Оттенок.** Нажмите кружок из палитры или выберите произвольный цвет. Цвет сразу применится к 3D и эскизам референсов.
2. **Отделка.** Crazy Horse — мягче и тянется лучше, предел кромки выше. Сафьян — жёстче, предел ниже, урез требует краски вместо воска. Приложение пересчитает вердикт по кромке и покажет тост с новым пределом.
3. **Толщина кожи.** Ключевой параметр:
   - картхолдеры: **0,8–1,6 мм** (при > 2 мм появится предупреждение о тугих слотах);
   - чехлы: **1,2–3,0 мм** (при < 1,2 — нужен усилитель, при > 3 — обязательное спускание и пробойник 4 мм).
4. **Патина.** Влияет только на визуализацию (плотность царапин), не на геометрию.
5. **Нить.** Кремовая даёт контраст, «в тон» — деликатный вид. Цвет виден на стежках в 3D.
6. **Подкладка.** Замша приятна на ощупь, но снижает гибкость (предел кромки падает на 5 %). Кожа 0,8 — на 10 %. Без подкладки — максимум гибкости и минимум расхода.

> После каждого изменения толщины/отделки/подкладки список моделей перезаполняется: пометки `▸ кромка` обновляются под новую кожу.

### Шаг 7. Работа с 3D-превью

1. **Вращение** — левая кнопка мыши или один палец. **Масштаб** — колесо или щипок. **Панорама** — правая кнопка или два пальца.
2. Кнопки в правом верхнем углу сцены:
   - ⟳ **Сброс камеры** — вернуть ракурс по габаритам изделия;
   - ↻ **Автовращение** — включить/выключить оборот;
   - ▭ **Наполнение** — показать/скрыть устройство или карты внутри;
   - 📷 **PNG** — скачать снимок с подписью.
3. В блоке **«06 · Студия»** настройте свет (сила и угол) — так лучше видно фактуру и урез.
4. Слайдер **Клапан / Раскрытие**:
   - чехлы с клапаном: 0° закрыт → 170° откинут, видна замшевая изнанка;
   - картхолдеры-книжки: 0° сложен → 180° раскрыт;
   - веер: 0° собран → 180° развёрнут.
5. **Качество**: «Высокое» для финальных снимков, «Эконом» на слабых устройствах.
6. Если 3D недоступно — включится 2D-эскиз с честной подписью. Все остальные разделы работают.

### Шаг 8. Изучение выкройки на экране

1. Перейдите к разделу **«07 · Раскрой»**. На «раскроечном мате» лежат все детали в масштабе.
2. Легенда линий:
   - **сплошная тёмная** — контур реза;
   - **пунктир красный** — линия шва;
   - **штрихпунктир синий** — сгиб / подгибка;
   - **пунктир синий вертикальный** — линия обхвата торца (только плоский крой);
   - **кружки и овалы с крестами** — отверстия и прорези под фурнитуру;
   - **треугольники по кромкам** — метки совмещения (центр низа, углы, концы молнии).
3. Переключатели **Швы** и **Подписи** убирают соответствующие слои — удобно для чистого контура.
4. **Экранная линейка**: приложите линейку к отрезку и подгоните слайдер, пока 100 мм на экране не станут ровно 100 мм. Это влияет **только на экранный просмотр** — PDF всегда в физических мм.

### Шаг 9. Проверка спецификации и контроля

1. Раздел **«08 · Документация»**:
   - 4 плитки: кожа с запасом, нить, вес кожи, листов A4;
   - таблица деталей: название, габариты кроя, количество, состав разметки;
   - список фурнитуры и расходников с точными размерами отверстий.
2. Панель **Контроль** справа: вердикт по кромке, посадке, припуску, толщине, раскладке, фурнитуре. Жёлтые пункты — не ошибка, а предупреждение.
3. Нажмите **Полная самопроверка** — получите список геометрических и печатных ассертов с числами (см. [Контроль и самопроверка](#контроль-и-самопроверка)).
4. **Скачайте спецификацию** мысленно или через техкарту (шаг 12) — она содержит те же данные в текстовом виде.

### Шаг 10. Расчёт и покупка кожи

1. Раздел **«09 · Расход»**. Задайте **запас** слайдером:
   - 10–12 % — если кожа уже проверена и детали умещаются в обрезок;
   - 15–20 % — стандарт для чехла;
   - 25–40 % — если кожа с дефектами, тянется неравномерно или вы новичок.
2. Изучите таблицу форматов. Два числа листов:
   - **По площади** — теоретический минимум;
   - **Раскладка** — реалистичная оценка с зазорами и поворотом.
   Если стоит `⚠` — деталь больше листа, нужен формат крупнее.
3. Выберите формат в селекторе — справа нарисовается раскладка первого листа с легендой по деталям.
4. Нажмите **Сравнить крой** — таблица покажет, сколько кожи и шва экономит плоский крой именно для вашего изделия. Иногда это 15–25 %.
5. **SVG раскладки** — скачать схему для распечатки или показа поставщику.

> Картхолдеры часто умещаются в обрезок 20×20 см. Проверьте этот формат первым — можно сэкономить целую кожу.

### Шаг 11. Скачивание раскроя

Кнопки скачивания есть в **трёх местах**: в шапке сайта, в панели под 3D-сценой и в разделе **«06 · Скачать»**.

1. Нажмите **Предпросмотр листов** — откроется модальное окно со всеми страницами A4.
2. Проверьте первый лист: отрезок 100 мм, квадрат 50×50, контур карты ID-1.
3. Выберите DPI:
   - **200** — быстро, для примерки;
   - **300** — стандарт печати (рекомендуется);
   - **400** — максимальная точность мелких деталей картхолдера.
4. Нажмите **Скачать PDF**. Индикатор покажет прогресс по листам.
5. Альтернативы:
   - **SVG в мм** — для Illustrator, Inkscape, CorelDRAW, лазерного реза, плоттера;
   - **PNG** — превью для согласования с заказчиком;
   - **Только калибровка** — если хотите сначала проверить принтер;
   - **Системная печать** — если PDF-движок недоступен.

### Шаг 12. Печать и калибровка

1. Откройте PDF в Acrobat Reader, Chrome или Preview.
2. В диалоге печати выставьте:
   - масштаб **100 % / Реальный размер** (не «Вписать», не «По размеру страницы»);
   - поля **Нет / Минимальные**;
   - колонтитулы **выключить**;
   - ориентация **книжная**, бумага **A4**.
3. Распечатайте **только первый лист**.
4. Приложите линейку: отрезок должен быть **ровно 100 мм**.
5. Приложите банковскую карту к контуру: края должны совпасть.
6. Если не совпало — проверьте драйвер принтера, отключите «масштабирование по умолчанию», попробуйте другой браузер или PDF-ридер.
7. Только после успешной калибровки печатайте остальные листы.

### Шаг 13. Склейка крупных деталей

Если деталь не поместилась на A4, она разбита на листы:

1. Найдите на листе **точки склейки**: `V1.1`, `V1.2` (вертикальные швы) и `H1.1` (горизонтальные).
2. Точка с тем же идентификатором есть на соседнем листе — это пара.
3. Совместите **кресты** по углам печатной области и точки V/H.
4. Склейте встык малярным скотчем с изнанки, не смещая контур.
5. Проверьте линейкой общий габарит собранной детали — он должен совпадать со спецификацией.

### Шаг 14. Изучение 3D-сборки

Раздел **«11 · Сборка»** — интерактивная инструкция по узлам.

1. Нажмите **▶ Проиграть** — приложение проведёт по 11 этапам, автоматически уменьшая разнесение слоёв.
2. Или щёлкайте чипы этапов / кнопки `‹` `›` для ручного изучения.
3. Слайдер **Разнесение** — насколько далеко разведены слои (0 % = собрано, 100 % = максимальная разборка).
4. Слайдер **Скорость** — темп автопроигрывания.
5. Переключатели слоёв:
   - **Швы** — стежки по линиям;
   - **Клей** — клеевые зоны по припуску;
   - **Фурнитура** — кнопки, магниты, заклёпки, ось, молния;
   - **Подкладка** — слой подкладки;
   - **Сгибы / обхват** — линии сгиба и обхвата торца;
   - **Подписи** — текстовые выноски узлов;
   - **Разрез** — скрыть переднюю панель на поздних этапах;
   - **Каркас** — wireframe для понимания геометрии.
6. Вращайте сцену мышью, чтобы рассмотреть узел с любой стороны.
7. Справа внизу — **SVG-разрез узла шва** в масштабе: кожа, подкладка, клей, второй слой или кромка, положение шва относительно края, величина спуска припуска.

### Шаг 15. Техкарта и изготовление

Под 3D-сборкой находится **техкарта** — четыре карточки и два блока предупреждений.

1. **Карта изделия** — все ключевые числа: линия, конструкция, тип кроя, предел кромки, габариты, вместимость, кожа, подкладка, шаг пробойника, иглы, стежки, урез, вес, время.
2. **Материалы и фурнитура** — точный список с размерами отверстий.
3. **Инструменты** — что подготовить до начала.
4. **Порядок изготовления** — нумерованные операции с конкретными величинами вашей модели.
5. **⚠ Критичные места** — предупреждения именно для этой конфигурации.
6. **✓ Практические советы**.
7. Экспорт:
   - **Скачать TXT** — текстовая техкарта для мастерской, печати на дешёвом принтере или отправки в мессенджер;
   - **Печать / PDF техкарты** — две страницы A4 с таблицей деталей и порядком операций.

Далее работайте по техкарте. Ключевые правила, которые приложение подчёркивает:

- **Спускание припусков** до 55–70 % толщины; зоны сгиба — до 40–50 %.
- **Фурнитура ставится ДО сшивания** — после замыкания шва доступа к изнанке нет.
- **Верх слота / верх чехла не зашивается.**
- **Клей только внутри линии шва.**
- **Плоский крой требует формовки** с наполнением на 12–24 ч.
- **Ось веера не перетягивать** — пластины должны вращаться.

### Шаг 16. Финальный контроль

1. Вставьте устройство или карты. Посадка должна быть плотной, но без усилия.
2. Проверьте работу фурнитуры: кнопка щёлкает, магнит держит, молния ходит, зажим не царапает.
3. Осмотрите шов: равномерный шаг, одинаковая затяжка, узлы спрятаны.
4. Осмотрите урез: гладкий, без ворса, глянец равномерный.
5. При необходимости вернитесь в конфигуратор, скорректируйте посадку и перепечатайте выкройку для следующего изделия.

## Техкарта изготовления

### Карта изделия

Линия, конструкция, тип кроя, предел кромки при текущем C, габарит изделия, вместимость (для карт), внутренний и внешний размер, прибавка на обхват, кожа и площадь, тип кожи, подкладка, шаг пробойника, иглы и нить, число стежков, длина уреза, вес, оценка времени.

### Материалы и фурнитура

Формируется динамически. Примеры строк:

- `Кожа 1.4 мм · 3.2 дм² с запасом 12%`
- `Нить вощёная 0,6 мм · 2.1 м · 2 иглы`
- `Кнопка альфа 12,5 мм · 4 отв. Ø3,5 (2 на клапане, 2 на площадке)`
- `Молния №3 · 274 мм · пуллер Ø5, 2 концевика`
- `Винт-пост Ø4 мм + шайба · ось веера, 7 слоёв`
- `Гофре: 6 секций · разделителей 5`

### Инструменты

Пробойник с рассчитанным шагом, иглы под нить, шило, киянка, мат, нож, линейка, лекала, спускатель, циркуль-разметчик на величину припуска, торцбил нужного номера, шлифовка 400/800/1200, сликер, воск или краска для уреза, зажимы, ролик, кость, пресс для кнопок, пробойники Ø по выкройке.

### Порядок изготовления

10–14 операций в зависимости от конструкции. Каждая содержит конкретные числа вашей модели: величину спуска в мм, ширину клеевой полосы, шаг слотов, длину молнии, размер корешка, число пластин, величину стежка, длину нити, размер болванки.

### Критичные места

Примеры предупреждений, которые генерируются автоматически:

- кромка отключена вручную при толщине выше предела;
- конструкция требует боковины по замыслу — отключить нельзя;
- кожа толще 2 мм для картхолдера — слоты будут тугими;
- больше 8 карт в плоском крое — рассмотрите аккордеон;
- ось веера: не перетягивать винт;
- кнопка и магниты ставятся до сшивания, проверить полярность;
- кожа тоньше 1,2 мм для чехла — нужен усилитель;
- припуск меньше 3 мм — риск прорезания;
- сафьян хуже тянется, урез красить краской.

## Контроль и самопроверка

### Панель контроля (автоматически)

| Проверка | Что смотрит |
|---|---|
| Кромка | Соответствие режима и предела, принудительность по конструкции |
| Посадка | Достаточность прибавки для линии |
| Припуск | Не слишком узкая зона шва |
| Толщина кожи | Попадание в рекомендованный диапазон линии |
| PDF | Число листов, наличие тайлинга |
| Карты входят | `finW ≥ A` для картхолдеров |
| Экономия кроя | Не включена ли кромка избыточно |

### Полная самопроверка (по кнопке)

1. **Кромка соответствует правилу** — наличие детали боковины совпадает с вердиктом.
2. **Габарит внутри ≥ изделия** — численное сравнение.
3. **Толщина во внешнем габарите** — `outer.c = depth + 2t` с точностью 0,01 мм.
4. **Шов на припуске** — замер расстояния от линии шва до контура по 40 точкам, разброс в допуске 0,4 мм.
5. **PDF A4 в физических мм** — все страницы содержат `width="210mm"`.
6. **Стежков посчитано** — положительное число стежков и шаг.

Результат выводится списком с ✓/✕ и числами, плюс тост `Самопроверка: N/M`.

## Точность и ограничения

### Что гарантировано

- Вся геометрия считается в миллиметрах с точностью до 0,01 мм.
- PDF-листы создаются в физических миллиметрах — размер не зависит от экрана и калибровки просмотра.
- Линия шва отстоит от контура ровно на величину припуска (проверяется самопроверкой).
- Все отверстия, прорези и метки присутствуют и на экране, и в PDF, и в SVG.

### Что требует проверки мастером

1. **Габариты устройств — справочные.** Один и тот же модельный ряд может отличаться по годам и регионам. Толщина часто указывается без ножек, камер, чехлов. **Измерьте штангенциркулем.**
2. **Толщина кожи неоднородна.** Заявленные 1,4 мм могут быть 1,2–1,7 мм по площади. Измерьте в нескольких точках и подставьте среднее или максимальное.
3. **Растяжимость конкретной кожи.** Формула предела — инженерная оценка на основе практики, а не лабораторное испытание. Мягкая хромовая кожа тянется больше, дублёная растительным способом — меньше. Пробуйте на обрезке.
4. **Раскладка — оценка.** Алгоритм прямоугольный, не учитывает форму деталей, дефекты, направление тянучести, кромку чепрака. Реальный расход может быть выше на 10–20 %.
5. **Оценка времени** — ориентир для планирования, зависит от навыка и инструмента.
6. **Плотность кожи 0,86 г/см³** — среднее значение; вес может отличаться на ±15 %.

### Чего приложение не делает

- Не строит лекала с учётом индивидуальных дефектов конкретной шкуры.
- Не рассчитывает подгибку с утолщением на углах для очень толстой кожи (> 3,5 мм) — требуется ручная корректировка.
- Не моделирует фурнитуру нестандартных размеров — только типовые позиции из списка.
- Не поддерживает импорт сторонних SVG/DXF.
- Не сохраняет проекты в файл — только текущее состояние в браузере.

## Диагностика проблем

| Симптом | Причина | Решение |
|---|---|---|
| 3D не появилось, надпись «Эскиз · 3D-библиотека недоступна» | CDN заблокирован или нет сети | Раскрой и PDF работают. Для 3D нужен доступ к `cdn.jsdelivr.net` |
| 3D не появилось, «WebGL недоступен» | Отключён WebGL или старый GPU | Включите аппаратное ускорение в браузере, обновите драйверы |
| Ничего не работает, красный баннер внизу | Ошибка скрипта | Откройте консоль (F12 → Console), прочитайте текст и номер строки из баннера |
| Баннер «Приложение не запустилось» | Модуль не стартовал (часто `file://`) | Запустите через локальный сервер |
| PDF не скачался, открылась системная печать | jsPDF недоступен | Печатайте через системный диалог, выбрав «Сохранить как PDF» и масштаб 100 % |
| Распечатка не 100 мм | Масштаб принтера | Выставьте 100 % / Реальный размер, поля «Нет», колонтитулы выкл. Проверьте драйвер |
| Кнопки скачивания серые | Гейтинг не закрыт | Выберите модель/формат **и** конструкцию |
| Кромка не отключается | Конструкция `ch_zip` или `ch_acc` | Боковина нужна по замыслу — это ожидаемо |
| Поле C нередактируемо | Линия «Картхолдеры» | Толщина считается из количества карт; меняйте счётчик или формат |
| Модель пропала из списка | Активен фильтр бренда или поиск | Сбросьте поиск, выберите «Все бренды» |
| Раскладка показывает `⚠` | Деталь больше листа | Выберите формат крупнее |
| 3D тормозит | Высокое качество на слабом GPU | Поставьте «Эконом», отключите автовращение |
| Состояние «сломалось» | Повреждённый `localStorage` | Нажмите «Сбросить всё» или очистите хранилище сайта |

## Структура файла

Приложение — один HTML-файл. Внутренняя организация:

```
atelier.html
├── <head>
│   ├── meta, title, favicon (data URI)
│   ├── Google Fonts
│   ├── importmap → three, three/addons/
│   └── <style>  ≈ 400 правил: токены, layout, компоненты, print, adaptive
├── <body>
│   ├── фоновые слои (aurora + grain)
│   ├── шапка с навигацией
│   ├── <main>
│   │   ├── мастхед + переключатель линий + чипы
│   │   ├── #studio   — колонка управления (00–06) + 3D-сцена + панель скачивания
│   │   ├── #rule     — правило кромки
│   │   ├── #download — карточки экспорта
│   │   ├── #pattern  — SVG-выкройка + линейка
│   │   ├── #spec     — спецификация + контроль
│   │   ├── #leather  — расход + сравнение + раскладка
│   │   ├── #refs     — референсы активной линии
│   │   └── #assembly — 3D-сборка + разрез + техкарта
│   ├── модальное окно предпросмотра PDF
│   ├── индикатор прогресса PDF
│   ├── #printRoot (скрыт на экране, виден при печати)
│   └── #toasts
├── <script>            watchdog: перехват ошибок + баннер
└── <script type=module>
    ├── утилиты
    ├── каталог DEVICES (laptop / tablet / ebook)
    ├── реестры CASE_DESIGNS, CARD_DESIGNS, CARD_FORMATS
    ├── палитры, отделки, нити, подкладки, форматы
    ├── состояние: DEF, san(), S, save(), ready()
    ├── правило кромки: flatLimit(), autoGusset(), useGusset(), wrapAllowance()
    ├── геометрия: fillet(), rectPoly(), insetPoly(), thumbNotchPoly()
    ├── раскрой: deriveCaseWith(), deriveCardWith(), finalize()
    ├── SVG: pieceSVG(), layout(), board(), calSVG(), tileSVG(), buildPages()
    ├── экспорт: downloadSVG(), exportPDF(), svgToCanvas(), sysPrint()
    ├── спецификация: hardwareList(), renderSpec(), renderChecks(), selfTest()
    ├── кожа: packSheets(), renderLeather(), renderCompare(), downloadNest()
    ├── текстуры: makeNoise(), heightField(), leatherCanvas(), suedeCanvas(), woodCanvas()
    ├── UI: fillModels(), fillDesigns(), syncUI(), renderAll(), setState()
    ├── Three.js: loadThree(), gridSurface(), makeStitches(), rrPath3(), rrShape()
    ├── студия: init3D(), buildCase3D(), buildCard3D(), rebuildScene(), animate()
    ├── сборка: stagesFor(), asmInit(), asmRebuild(), asmApplyStage(), asmLoop()
    ├── техкарта: techData(), renderTech(), techText(), techPrint()
    ├── референсы: CASE_REFS, CARD_REFS, refArt(), buildRefs()
    └── привязки: bindUI(), switchFamily(), старт в try/catch
```

### Ключевые архитектурные принципы

- **Единый источник размеров.** `derive()` — одна функция, возвращающая модель `M`, из которой рендерятся все представления.
- **Полиморфизм линий.** `deriveWith(gusset)` диспетчеризует на `deriveCaseWith` / `deriveCardWith`, обе возвращают одинаковую структуру `M`.
- **Консервативный синтаксис.** Без `??`, `?.`, `??=`, `**`, без слитных тернарников с десятичными литералами — максимальная совместимость и отсутствие ошибок парсинга.
- **Явное освобождение ресурсов.** Массивы `geos`, `texs`, `insts` для сцены и `ageos`, `atexs`, `ainsts` для сборки; полная утилизация перед перестройкой.
- **Graceful degradation.** Каждый внешний слой имеет fallback: 3D → 2D-эскиз, PDF → системная печать, фото референсов → процедурный эскиз.
- **Наблюдаемость.** Watchdog + `window.onerror` + баннер с номером строки вместо тихого отказа.

## Практические советы

### Кожа

| Изделие | Толщина | Дубление |
|---|---|---|
| Минимал-слип для карт | 0,8–1,2 мм | Растительное, плотная |
| Слотовый картхолдер | 1,0–1,6 мм | Растительное |
| Бифолд / лонг | 1,2–1,8 мм | Растительное или комби |
| Чехол для тонкого ноутбука | 1,6–2,2 мм | Растительное для формы, хром для мягкости |
| Чехол с кромкой | 2,0–2,8 мм | Растительное |
| Скрутка | 1,2–1,8 мм | Хром, мягкая |

### Инструмент под толщину

| Толщина кожи | Шаг пробойника | Иглы | Нить |
|---|---|---|---|
| ≤ 1,2 мм | 3,0 мм | №6–№8 | 0,45–0,6 мм |
| 1,2–2,0 мм | 3,0–3,5 мм | №4–№6 | 0,6–0,8 мм |
| 2,0–3,0 мм | 3,5 мм | №4 | 0,8 мм |
| ≥ 3,0 мм | 4,0 мм | №2 | 1,0 мм |

### Порядок, который нельзя нарушать

1. Спускание → до склейки.
2. Фурнитура → до сшивания.
3. Молния → до замыкания бокового шва.
4. Формовка → после сшивания, до финального ухода.

### Уход за готовым изделием

- Кондиционер раз в 3–6 месяцев.
- Не мочить, не сушить на радиаторе или феном.
- Хранить с болванкой или картами внутри — кожа запоминает форму.
- Crazy Horse: царапины затираются воском или тёплым пальцем.

## Возможные направления развития

- Импорт габаритов из CSV/JSON для собственных каталогов устройств.
- Сохранение и загрузка проектов в файл (`.json`) и библиотека изделий.
- Экспорт DXF для лазерного реза.
- Учёт подгибки с утолщением на углах для толстой кожи.
- Библиотека нестандартной фурнитуры с параметрическими отверстиями.
- Многопользовательские пресеты кожи (реальные замеры толщины и растяжимости).
- Nesting-алгоритм с учётом формы деталей (no-fit polygon) вместо прямоугольного.
- Учёт дефектов шкуры: разметка зон и автоматическое размещение деталей вне них.
- Расчёт себестоимости: цена кожи за дм², фурнитура, время × ставка.
- Печать бирок и упаковки, QR-код на техкарту.
- PWA: офлайн-кэш Three.js и jsPDF через Service Worker.
- Экспорт 3D-модели в glTF для просмотра в AR.

## Дисклеймер

Приложение — **инженерный помощник**, а не замена измерению и пробнику.

- Габариты устройств в каталоге справочные и могут отличаться от вашего экземпляра.
- Формула предела кромки — оценка на основе практики кожевенного дела, а не результат испытаний конкретной кожи.
- Раскладка и расход — приближение; реальная шкура имеет края, дефекты и неравномерную тянучесть.
- Оценка времени и веса — ориентировочная.

**Всегда проверяйте калибровку печати линейкой и картой, а посадку — на пробнике из обрезка, прежде чем резать дорогую кожу.**
